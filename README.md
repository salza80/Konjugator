# Konjugator

A falling-text German conjugation game built with Phaser 4 and Vite.

## Development

Use Node.js 24.22.1 LTS (pinned in `.nvmrc`).
With nvm installed, run `nvm use`, then:

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite (normally http://127.0.0.1:5173).
Static assets live in `public/assets` and are served at `assets/`.

## Commands

- `npm run dev`: start the development server.
- `npm run build`: create a static site in `dist/`.
- `npm run preview`: serve the production build locally.
- `npm run deploy`: alias for build; does not publish anything.
- `npm run lint`: run ESLint correctness checks.
- `npm test`: run Vitest once.
- `npm run test:watch`: start Vitest in watch mode.

Vitest is configured, but the gameplay test suite is intentionally deferred.
Until tests are added, the test command explicitly allows no test files.
The production build may report a large chunk because it includes Phaser.

## Embedding and configuration

The demo starts the game from `src/bootstrap.js`. A same-origin parent iframe
can provide `window.gameConfig`; see `iframeTest.html`. Cross-origin frames
use the default configuration.

The game module exports `startGame`:

```js
import { startGame } from './src/main.js';

const game = startGame({
  start_text: 'Konjugiere das verb! Bist du bereit?',
  asset_path: 'assets/',
  input_type: 'Keyboard'
});
```

Serve the contents of `public/assets` at the configured asset path. Optional
configuration includes `words` (an array of question/answer/tip/voice objects),
`words_url`, and `game_over_callback`. Available input types are `Keyboard`,
`Touch`, and `Voice`; omit `input_type` to show the selection screen.
Speech input requires browser support and microphone permission.

For deployment, publish `dist/`. The relative Vite base supports hosting under
a subdirectory. The historical `docs/` output is not regenerated by this build.

## Playing and checking the game

Choose keyboard, mobile/touch, or voice input from the menu. Keyboard answers
use Enter to fire and Backspace to edit; 1, 2, 3, and 4 insert ä, ö, ü, and ß.
Touch players select a falling question, then tap character groups to complete
its answer. Spaces are inserted automatically. Use Menu to leave a game.
After game over, click or press X to return to the menu.

On mobile, portrait view pauses play until you rotate and press Continue.
If speech recognition is unavailable, voice mode falls back to keyboard input.
Microphone access and speech recognition depend on the browser; live voice
recognition and physical mobile devices still need a manual check.

Custom word arrays must contain at least one non-empty `question` and `answer`.
`words_url` resolves relative to the embedding game page, independently of
`asset_path`. Loading failures and invalid word data display a retry screen.

Phaser is the runtime dependency. Vite, Vitest, ESLint, its configuration, and
browser globals are development dependencies. Static hosting only needs the
built `dist/` files, with no Node server or installed packages in production.
